### Hi, I'm Yao-Wen Liu

Wi-Fi baseband / firmware engineer at **Realtek Semiconductor**, working on 802.11ax/be/bn MAC-layer scheduling (OFDMA RU allocation), driver-firmware integration, and monostatic CSI-based wireless sensing on embedded platforms (primarily ARM Cortex).

#### What I'm working on
- Maintaining Wi-Fi 7 (802.11be) production firmware — designed and integrated dynamic OFDMA RU allocation supporting preamble-puncturing scenarios; extending the Wi-Fi 8 (802.11bn) driver-firmware control plane
- Building monostatic CSI-based respiration sensing — adapt published algorithms and re-architect them around our application and embedded constraints; extended detection range **2m → 3m+** (≥80% accuracy) and cut CPU usage **18% → 5%** via NEON/VFPv4 intrinsics and bit-exact fixed-point reformulation
- Architecting a unified regression-testing framework for the CSI algorithm team
